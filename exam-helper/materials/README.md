# 出题资料（与题库一体）

| 文件                       | 说明                                 |
| -------------------------- | ------------------------------------ |
| `Java开发手册(黄山版).pdf` | 官方公开 PDF                         |
| `Java开发手册(黄山版).txt` | PDF 提取文本，**运行时 AI 组卷读取** |

## 与系统的关系

```
materials/*.txt  ──运行时──→  抽取【强制】/【推荐】片段
                                    ↓
                              DeepSeek AI 出题
                                    ↓
                         L2 练习组卷（50 / 15 题）
                                    ↓
              不足时 fallback → data/questions.js（86 题预置库）

划词 ⌃⇧A：预置库 + 当前卷子 AI 题 → 匹配；未命中且有选项 → AI 推理
```

- **L2 / 快刷**：从 TXT 动态 AI 组卷（需 popup 配置 DeepSeek 密钥）
- **预置题库**：`data/questions.js`，AI 不足时补齐，也可手动离线组卷 fallback
- **增补预置题**：在 `.txt` 查规约 → 追加 `questions.js`（与 AI 组卷并行存在）
