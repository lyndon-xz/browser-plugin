## M1：走通骨架（walking skeleton）

> 端到端最薄切片：GitLab MR 页判定 → 一条评论旁挂入口 → 点开抽屉 → 用 `position.head_sha` 调 API 取到评论时版本的代码 → 高亮锚点行渲染出来。
> 这一刀穿透 DOM 注入 / 鉴权 / API 取数 / Shadow DOM 渲染四层，把 architecture.md §6.3 的三条待验证项全部逼出来。
> 完成后：系统端到端可跑通，骨架就绪；此模块验收通过前其余模块不并行启动。
