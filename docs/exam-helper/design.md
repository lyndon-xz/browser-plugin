# 设计文档 — Exam Helper（交互与视觉）

> 说明：本文件在工作区丢失后按会话记录重建，忠实于气泡原型（`designs/bubble-prototype.html`）与其它文档反复引用的设计决策（DD-3 debounce 300ms、DD-4 取消即消失/无退场动效、Shadow DOM 隔离等）。

## 1. 交付形态

纯前端 Chrome 扩展，两处界面：

- **答案气泡**（注入式 overlay）：覆盖在宿主考试页之上，随文本选区浮现/消失，不改变宿主页布局。
- **扩展 popup**（工具栏点击）：本机配置 DeepSeek 密钥、查看启用状态；密钥不进源码。

---

## 2. 设计目标

- **零操作**：选中题目即出答案，不需要点击按钮或再按键。
- **不打扰**：气泡浮层不遮挡答题、不接管鼠标（`pointer-events:none`），可一键全局关闭。
- **看一眼就懂**：答案（选项字母）最醒目，辅以题型、简要解析与来源标识。
- **与宿主页零冲突**：样式、DOM 完全隔离，不被页面 CSS 影响也不影响页面。

---

## 3. 交互流程

```
选中题干文字 ──(debounce 300ms)──▶ 匹配题库
     │                                  ├─ 命中 → 气泡浮现在选区下方（命中态）
     │                                  └─ 未命中 → 气泡显示「AI 推理中…」→ AI 答案态 / 错误态
     └─ 取消选区 / 清空 ─────────────▶ 气泡立即消失
```

- **触发**：监听 `selectionchange` / `mouseup`；debounce 300ms 后取选区文本（DD-3）。
- **定位**：气泡出现在选区**下方**，左端对齐选区左缘，顶部带一个指向选区的三角箭头。
- **消失**：取消选区立即隐藏，无退场动画（DD-4）；入场用轻微 fadeIn（.15s）。
- **全局开关**：Alt+Q 启用/禁用；禁用时不响应选区并隐藏已有气泡（详见 requirement V-4）。
- **本机密钥**：点击工具栏图标打开 popup，在「本机密钥」栏粘贴并保存；未配置时题库未命中走错误态，文案引导回 popup 填写（V-8）。

## 4. 气泡内容（信息架构）

| 区域 | 内容 | 说明 |
| ---- | ---- | ---- |
| 答案徽章 | 正确选项字母，如 `B C D` | 荧光笔划线，墨色字，最醒目 |
| 题型标签 | 「单选」/「多选」 | 徽章右侧小字 |
| 解析 | 一句简要解析 | 命中题库时展示，可空 |
| 来源标签 | 「📚 题库命中」/「🤖 AI 推理」 | 让用户知道答案来自题库还是 AI |

## 5. 视觉规范（取自原型）

| 元素 | 规格 |
| ---- | ---- |
| 共用色板 | 雾蓝底 `#E8EDF4` / 白卡片 `#FFF` / 墨 `#2F3640` / 辅文 `#6B7380` / 荧光笔 `#FFE58A`（只划答案字母） / 鼠尾草 `#5E8F7B` / blush `#C45C5C` |
| 气泡卡片 | 半透明白 `rgba(255,255,255,.92)` + 毛玻璃 blur 14px，细墨描边 10% 透明度，圆角 `16px`，宽 `340px`，分层阴影；不换卡片底色 |
| 三角箭头 | 12×12 旋转 45°，白底 + 同色描边，圆角 `3px`，`left:22px` |
| 答案字母 | 墨色字 + 荧光笔下划（`linear-gradient(transparent 58%, #FFE58A 58%)`），`font-weight:700`，`16px` |
| 题型标签 | 辅文 `#6B7380`，`11px` |
| 解析文字 | `#5A6270`，`12.5px` |
| 来源标签 | 辅文小字，无描边 pill |
| 正文字色 | `#2F3640` |
| 入场动画 | `bubbleFadeIn .18s ease-out`（位移 6px + 透明度） |

## 6. 三种状态

| 状态 | 触发 | 呈现 |
| ---- | ---- | ---- |
| 命中态 | 题库匹配成功 | 答案徽章 + 题型 + 解析 + 「📚 题库命中」 |
| AI 推理中 | 未命中、等待 DeepSeek | spinner + 「AI 推理中…」 |
| 错误态 | DeepSeek 失败/超时/未配置密钥 | blush 文案 `#C45C5C`；未配置时为「还没填写 DeepSeek 密钥，点工具栏图标打开弹窗即可」 |

> 三态视觉见 `designs/bubble-prototype.html`。命中态在 M1 落地；AI 推理中/错误态在 M3 接入（气泡组件三态在 M1 一并实现）。未配置密钥的错误文案在 I1 落地（V-8）。

## 7. 技术约束（影响架构）

- **Shadow DOM 隔离**：气泡挂在 `document.body` 下一个 shadow host（`mode:"open"`），样式全部内联注入 shadow-root，`:host { all: initial }` 阻断宿主页样式继承（V-3）。
- **不接管交互**：容器 `pointer-events:none`，`z-index` 极大值置顶。
- **定位坐标**：用选区 `getBoundingClientRect()` 的视口坐标，气泡 `position:fixed`。
- **隐藏语义**：`hide()` 清空内容并 `display:none`，使 host 尺寸为 0。

## 8. 设计决策记录（DD）

| 编号 | 决策 | 理由 |
| ---- | ---- | ---- |
| DD-1 | popup 软白卡片 + 气泡半透明白 + 荧光笔只划答案字母 | 装订线/直角/砖红太僵；整张卡片换黄会像「考黄」 |
| DD-2 | 气泡定位选区下方 + 三角箭头 | 明确指向所选题目，不遮挡题干 |
| DD-3 | 选区监听 debounce 300ms | 拖选过程会连续触发 selectionchange，防抖避免频繁匹配与闪烁 |
| DD-4 | 取消选区气泡立即消失、无退场动效 | 快速跟手、不拖影；仅入场用轻 fadeIn |
| DD-5 | Popup 密钥用圆角输入 + 独立保存钮；已保存只露 `sk-••••` 末 4 位 | 密钥是本机凭证；全量回显会把 key 暴露在屏幕上 |
| DD-6 | 未配置密钥时不发 DeepSeek 请求，气泡走既有错误态、文案指向 popup | 空 key 打 API 只会 401；引导回 popup 比泛化的「网络错误」可执行 |
| DD-7 | 浅色、大圆角、禁止夜纸底 / 亮绿章 / 装订线 / 宋体标题 | 用户要柔和；frontend-design 也不规定暗色或硬边报纸风 |
| DD-8 | 白叠白不靠换底色：细描边 + 分层阴影 + 毛玻璃 | 考试页多为白底；整卡换黄不接受 |

## 9. Popup 面板

- **功能说明**：查看自动匹配是否启用；在本机填写/更新 DeepSeek API key（V-8）。
- **布局说明**：白底软卡片，圆角 `18px`。标题系统黑体。启用状态是鼠尾草绿点 + 胶囊。本机密钥：浅底圆角输入，旁边独立保存钮（空=荧光笔黄、保存后=鼠尾草）。
- **交互说明**：打开即读 storage 渲染「未配置 / 已保存」；粘贴 key 后点「保存」写入 `chrome.storage.local`；输入为空时保存钮不可用；已保存后可再贴新 key 覆盖。
- **配色**：雾蓝 `#E8EDF4` / 白 `#FFF` / 墨 `#2F3640` / 辅 `#6B7380` / 荧光笔 `#FFE58A` / 鼠尾草 `#5E8F7B` / blush `#C45C5C`
- **设计产物**：`designs/popup-prototype.html`
- **对应验收标准**：V-8（定义见 requirement.md §4）
