# 需求文档 — Exam Helper

> 说明：本文件在工作区丢失后按会话记录重建，忠实于其它文档（architecture / implementation / acceptance）中反复引用的验收标准（V-1~V-7）、用户故事（US-1~US-4）与关键决策。§8 资源清单与变更记录为原文保留。

## 1. 背景与目标

考试（阿里巴巴 Java 编码规范认证等）为在线选择题形式。使用者希望在答题时，选中题目文字后能立即看到参考答案，减少来回查资料的成本。

- **交付形态**：Web/前端 — Chrome 扩展（Manifest V3），注入式 overlay，无自建后端。
- **核心价值**：选中题目文字即出答案；本地题库优先，未命中用 AI 兜底。
- **使用范围**：个人使用，不公开分发。

## 2. 用户故事

| 编号 | 用户故事 |
| ---- | -------- |
| US-1 | 作为考试者，我在题目上**选中题干文字**时，希望在选区附近**自动浮现**答案气泡（题库命中），无需点击或额外操作；取消选区气泡随即消失。 |
| US-2 | 作为考试者，我希望能用一个**全局快捷键（Alt+Q）**随时启用/禁用自动匹配，避免在不需要时干扰阅读。 |
| US-3 | 作为考试者，我希望题库尽量**覆盖全量真题**，让大部分题目选中即可秒出答案。 |
| US-4 | 作为考试者，遇到**题库没有的题**，我希望用 **AI（DeepSeek）兜底**给出建议答案，而不是一无所获。 |

## 4. 验收标准

| 编号 | 验收标准 | 关联 |
| ---- | -------- | ---- |
| V-1 | 选中题目文字后，答案气泡自动浮现在选区下方并展示答案；取消选区（点开别处/清空选区）气泡立即消失。 | US-1 |
| V-2 | 模糊匹配：即使选中的题目文字与题库存在**语序不同、多余空格、全半角/标点差异、部分截断**，仍能命中正确题目。 | US-1 |
| V-3 | 气泡使用 **Shadow DOM** 渲染，样式与宿主页完全隔离、不修改宿主页元素、不遮挡页面交互（pointer-events:none）。 | US-1 |
| V-4 | 通过全局快捷键 **Alt+Q** 启用/禁用自动匹配；禁用时选中不弹气泡、图标切换为 inactive；再次按下恢复。 | US-2 |
| V-5 | 题库覆盖阿里巴巴 Java 规范认证的全量真题，常见真题选中即命中并显示正确答案。 | US-3 |
| V-6 | 题库未命中时调用 DeepSeek：气泡先显示「AI 推理中…」，随后展示 AI 返回的答案。 | US-4 |
| V-7 | DeepSeek 调用失败（网络/超时/错误）时，气泡显示友好错误提示，不白屏、不崩溃。 | US-4 |

## 6. 非功能需求

| 维度 | 要求 |
| ---- | ---- |
| 兼容性 | Chrome 88+（Manifest V3）。 |
| 性能 | 题库模糊匹配单次 < 100ms（选中到出结果无明显延迟）；选区监听 debounce 300ms。 |
| 网络 | DeepSeek 请求 5s 超时。 |
| 隐私 | 不采集、不上传选区内容到除 DeepSeek 外的任何端点。 |
| 健壮性 | 扩展重载导致的孤儿 content script、API 失败等异常均静默降级或友好提示，不影响宿主页。 |

---

## 7. 范围外（Out of Scope）

- 题库在线更新 / 云端同步（题库随扩展打包，静态分发）。
- 多浏览器（Firefox/Edge）适配。
- 账号、登录、付费等。
